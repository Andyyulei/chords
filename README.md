# Voicing Studio · 和弦练习工坊

从罗马数字级数制作可编辑的吉他／钢琴练习材料。纯浏览器应用，无需账号、后端、API 密钥，运行时无在线服务依赖。

## 开发

需要 Node.js 22.12+（本环境已使用 Node 24 验证）。

```sh
npm ci
npm run dev
```

云环境若默认 npm 缓存不可写，使用 `npm ci --cache /workspace/.npm-cache`。现有隔离任务直接使用本检出目录，无需另建 Git worktree。

```sh
npm test             # 音乐模型、移调事务、导入校验
npm run build        # TypeScript 检查 + 生产构建
npm run test:layout  # 多宽度、缩放、控件边界与钢琴滚动回归；先启动开发服务
npm run test:browser # 先另开终端运行 npm run dev，再执行浏览器验收
```

浏览器验收默认使用 `/usr/bin/chromium`，可通过 `CHROMIUM_PATH` 指定其他 Chromium 可执行文件。截图与 PDF 写入 `artifacts/`。CI 执行单元测试和生产构建；浏览器验收已在云环境本地执行，未在 GitHub Actions 中运行。

## 使用

1. 打开默认 C 调 ii7–V7–Imaj7–vi7 示例，或选择八个内置模板之一。
2. 每列独立更改级数、变化音、性质与两种乐器候选。
3. “编辑指板”后点击品位，或用 X／0 与精确品位输入；移动窗口可访问 1–24 品。
4. “编辑琴键”后选择左手／右手，点击音符添加、转移或移除。键盘支持横向滚动 C2–C6，选音保留在窗口外。当前选音自动居中；可用左右按钮、触控板／手势滑动或聚焦滚动区域后按方向键浏览，“定位当前选音”可以返回当前配音。
5. 撤销／重做作用于整个材料的最近 50 次数据操作，重置预置也可撤销。图形修改不会自动更改和弦名称。
6. 更改调性先看事务预览；不能平移的吉他可明确选择替换预置，钢琴超界则需八度修正或取消。更改已有自定义的和弦定义会先询问保留／替换／取消。
7. “保存材料”写入命名材料库；“另存副本”产生独立材料。“我的材料”中可打开、导出和确认删除。当前草稿自动保存；切换模板前另存备份，“恢复切换前草稿”可找回最近一次切换前的数据。
8. JSON 导入／导出用于离线备份与跨设备转移；可导入 `examples/edited-sheet.json` 检查自定义音的恢复。
9. 选择双乐器或单乐器，再点击“打印／另存为 PDF”。四列一页，5–8 列分两页。打印使用当前实际音，不重新生成预置。

浏览器数据仅存于当前来源下的 localStorage。换域名、清理浏览器数据、隐私模式限制可能影响可用性，请定期导出 JSON。存储写入失败会明确显示未保存，仍可导出当前材料。

## 音乐约定与限制

级数坐标使用大调音阶 `[0,2,4,5,7,9,11]`，性质显式保存。标准调弦低到高 E2 A2 D3 G3 B3 E4；C4 = MIDI 60。音名按和弦拼写，音程与实际八度分别计算；额外音标 *，省略音按音级去重检查。

吉他候选由本项目规则生成，满足音域与构成音检查，**未经过人工可弹性筛选**；不要把候选当作推荐指法。吉他不显示手指数字或横按标记。钢琴候选为紧密排列与两个转位。P1 试听与单图 SVG 导出未实现。
